# حزمة تحديثات تصميم وأداء تطبيق نبض (nabd_web)

تحتوي هذه الحزمة المضغوطة على كافة تعديلات الهوية البصرية الجديدة (**الألوان الكحلية والسماوية** + خط **Cairo & Readex Pro**) وتحسينات الأداء والتخزين المؤقت لمستودع `https://github.com/ahm-0/nabd_web.git` مع الحفاظ التام (100%) على بيانات التطبيق وربط **Supabase** و**OneSignal**.

## محتويات الملف المضغوط
1. **`apply_and_push_nabd.sh`**: سكربت تلقائي متكامل يقوم بسحب أحدث نسخة من المستودع، وتحديث جميع ملفات `.css` وجميع صفحات `.html` (أكثر من 40 صفحة) وملف `sw.js` مع الحفاظ على كافة الأكواد الموجودة، ثم عمل `Commit` و`Push` مباشر إلى GitHub.
2. **`material-ui.css`**: نظام التصميم المحدث (Material 3 Navy & Sky Blue Edition) جاهز للرفع المباشر.
3. **`nabd-ui.css`**: تنسيقات واجهة نبض المحدثة بالألوان الكحلية والسماوية والخط العربي المميز.
4. **`styles.css`**: ملف المتغيرات والتنسيقات الأساسية المحدث بالألوان الكحلية والسماوية وخط Cairo.
5. **`sw.js`**: ملف Service Worker المطور لتحسين الأداء وتسريع التحميل وتخزين الخطوط محلياً.
6. **`manifest.json`**: ملف إعدادات تطبيق الويب التقدمي (PWA) محدثاً باللون الكحلي الأساسي `#071324`.

## طريقة الاستخدام والرفع إلى GitHub

### الطريقة الأولى: التحديث الشامل والرفع التلقائي (موصى بها)
ضع ملف `apply_and_push_nabd.sh` داخل مجلد المشروع (أو في Replit / الطرفية) وشغّل الأمر:
```bash
bash apply_and_push_nabd.sh
```

### الطريقة الثانية: الرفع اليدوي عبر واجهة GitHub
1. فك الضغط عن الملف `nabd_web_updates.zip`.
2. افتح رابط المستودع `https://github.com/ahm-0/nabd_web` واضغط على **Add file > Upload files**.
3. اسحب الملفات المحدثة (`material-ui.css`، `nabd-ui.css`، `sw.js`، `manifest.json`) واضغط على **Commit changes**.
